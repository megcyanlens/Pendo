# Pendo: Scopes step 1

Clicking anywhere on the header row (`#pendo-row-c7986eb9`) clicks its button (`#pendo-button-6411e4eb`), so the row does whatever that button's Pendo action is. The row shows a pointer on hover.

## Install

Add a Code block to the step and paste `step1.js` into its JS tab. The HTML and CSS tabs stay empty.

If either element gets a new ID in Pendo, update `HEADER_ROW_ID` or `HEADER_BUTTON_ID` at the top of the JS.
